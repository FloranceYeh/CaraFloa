# 一只缓慢经过的蓝色茶壶

清晨的时候，窗帘并没有完全拉开，光线像一层不太确定的薄雾，停在桌面上，既没有继续向前，也没有完全退回去。桌角放着一只蓝色茶壶，壶嘴朝向没有人坐着的那把椅子。没有人知道它为什么在那里，也没有人打算把它拿走。椅子旁边有一双鞋，鞋带已经松开，但鞋子仍然端正地并排放着，好像它们正在等待一个迟到的脚步。

房间里最响亮的声音来自墙上的钟。它每走一步，就把前一步轻轻擦掉，仿佛时间不是流动的水，而是一块不断被修改的黑板。窗外有一棵树，树叶在风里反复点头，点到一半又突然停住。远处传来一声汽车喇叭，接着是一阵并不对应任何事情的安静。安静持续了很久，久到桌上的灰尘似乎也有了自己的方向。

中午以前，茶壶的颜色变得更蓝了一些。有人在纸上写下“蓝色”，又在旁边写下“茶壶”，然后觉得这两个词靠得太近，于是把它们之间的距离拉开。纸张因此出现了一条折痕，折痕从左上角走到右下角，途中经过一个句号，句号没有躲开。纸张背面什么也没有，但如果把它举到光下，就会看见一些模糊的白色线条，像是某种没有完成的地图。

下午的风带来一片叶子。叶子落在门口，翻了三次面，最后停在一块看不出形状的影子里。影子慢慢变短，叶子却没有移动。后来天色暗下来，房间里的物品开始失去边缘，茶壶、椅子、鞋子、纸张和那条折痕都混在一起，成为一种没有名称的深蓝色。有人说，所有物品在夜里都会变成同一件物品，只是白天看不出来。

> 💡 有些事情没有开头，也没有结尾，只是在某个时刻恰好占据了视线。

## 一段重复但不完全相同的描述

蓝色茶壶仍然在那里。它没有装水，也没有发出声音。壶盖与壶身之间留着一圈细小的缝隙，缝隙里藏着一点灰尘，一点光，以及一件无法确认是否存在的事情。把它从左边看过去，它像一座很小的房子；从右边看过去，它又像一只低头的鸟；从正面看过去，它只是一个蓝色茶壶。三种看法互不承认，却同时成立。

桌面上的纸被风吹动了一下。折痕依然在原来的位置，句号也依然没有躲开。只是那条模糊的白色线条似乎比之前长了一点，长到碰到了纸张的边缘。没有人测量它，也没有人解释它。一个没有解释的线条，就这样从上午经过下午，又从下午经过夜晚，最后进入了一个没有日期的清晨。

## 代码示例

```ts
type Teapot = {
  color: string;
  temperature: number;
  sounds: string[];
};

const teapot: Teapot = {
  color: "blue",
  temperature: 17,
  sounds: ["滴答", "沙沙", "没有声音"],
};

console.log(`${teapot.color}: ${teapot.temperature} degrees`);
```

## 公式示例

如果把一只茶壶经过房间的时间想象成某种没有意义的变化，可以写成：

$$
p = 0.5 \times blue + 0.3 \times silence + 0.2 \times shadow
$$

这个式子没有实际用途，正如窗外那朵云没有目的地一样。
