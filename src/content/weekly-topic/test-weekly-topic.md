# 一场没有结论的下午

下午三点十七分，天空突然变得很宽。宽到街道尽头的那栋房子显得像一枚被遗忘的纽扣，宽到风从窗户进来以后找不到出口，只好在房间里绕圈。桌上摆着三个杯子，杯子里没有水，水在别的地方，别的地方又没有杯子。这个关系并不复杂，却没有人愿意花时间说明。

有一只橘猫从门边走过。它的脚步很轻，每一步都像在地板上盖一个看不清楚的印章。猫走到墙角，抬头看了一会儿，仿佛墙上挂着一扇只有它能打开的门。墙当然没有回应。墙一直保持沉默，沉默得十分完整，连一粒灰尘都没有掉下来。

楼下有人搬动箱子。箱子碰到台阶，发出咚、咚、咚的声音。每一声之间的距离都不一样，于是听起来不像搬运，更像某种犹豫。声音持续了十几分钟，又在某个没有特别之处的瞬间消失。此后，空气里还留着几声不存在的回响，它们彼此追逐，最后藏进了窗帘的褶皱。

## 没有答案的清单

1. 一朵云为什么要经过屋顶？
2. 三粒米能不能组成一条路？
3. 如果影子迟到，它会先向谁道歉？
4. 黄色的门把手是否知道门的名字？
5. 一句话被说完以后，是否仍然占据原来的位置？

这些问题并不等待回答。它们被写在纸上，只是因为纸面空着，空着的地方容易让人误以为需要填满。纸张的边缘有一道毛刺，毛刺弯向左边，又因为光线的变化看起来弯向右边。🌱

## 继续绕圈

傍晚时，房间里的三个杯子被移动了半厘米。没有人承认移动过它们，杯子也没有留下任何证据。最左边的杯子看起来比之前更圆，中间的杯子看起来比之前更安静，最右边的杯子则像是在等待某种并不存在的信号。窗外的树影经过玻璃，短暂地把三个杯子连成一条线。

夜晚没有立即到来。它先派来一小块灰色，停在窗台上，然后派来另一小块灰色，停在门后。两块灰色互不相识，却都被称作夜晚。后来它们合在一起，房间变得没有方向，连那只橘猫也暂时忘记了墙角在哪里。

## 代码示例

```python
questions = ["云", "杯子", "影子", "门把手"]
for index, question in enumerate(questions, start=1):
    print(f"{index}. {question}")
```

如果把下午绕圈的次数记作 $n$，那么桌面上没有发生的事情可以粗略写成：

$$
quiet_n = quiet_0 \times (1 - r)^n,\quad 0 < r < 1
$$
