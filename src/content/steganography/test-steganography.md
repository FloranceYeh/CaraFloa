# 四只在雾里排队的鹅

雾是在凌晨出现的。它没有声音，也没有重量，却把远处的路牌变得比近处的石头更模糊。四只鹅站在路边，一只比一只白，一只比一只安静。它们没有向前走，也没有向后退，只是把脖子朝着同一个方向伸长，好像远方有一扇门，而门后有人正在数数。

第一只鹅的左脚旁有一根草。草尖挂着水珠，水珠里倒映着一小块灰色天空。第二只鹅的影子被雾切断了，只剩下半个翅膀形状。第三只鹅看起来像两只鹅，因为它正好站在一面积水旁边。第四只鹅没有影子，或者它的影子已经提前走到了桥的另一边。

没有人知道它们为什么排队。路上没有车，没有人，也没有售票处。队伍的长度因此变得没有意义，但四只鹅仍然保持距离，距离大约等于一只鹅半闭的眼睛。它们偶尔发出低沉的声音，声音在雾中变成四个方向，又从四个方向回来。

## 一张没有用途的表格

| 鹅     | 颜色         | 等待的方向 |
| ------ | ------------ | ---------- |
| 第一只 | 白色偏灰     | 北边的雾   |
| 第二只 | 白色偏蓝     | 看不见的桥 |
| 第三只 | 水里的白色   | 左边又右边 |
| 第四只 | 没有确定颜色 | 所有方向   |

表格完成以后，雾变厚了一点。纸上的字没有被打湿，但每个字旁边都多了一圈淡淡的光。🔍

## 桥的另一边

太阳出来之前，桥上出现了一枚纽扣。纽扣是棕色的，中间有两个孔，孔里穿不过风，也穿不过雾。第一只鹅低头看它，第二只鹅绕开它，第三只鹅把倒影里的纽扣叼走，第四只鹅什么也没有做。于是纽扣同时留在桥上，又不在桥上。

远处的钟响了三次。第一次之后，队伍缩短了一点；第二次之后，第三只鹅的影子回来了；第三次之后，雾开始向天空移动。四只鹅依然没有通过桥。它们只是从原来的位置，变成了另一个原来的位置。这个变化没有被任何地图标记，也没有人因此迟到。

## 一段较长的分析

隐写测试不能只看“能不能藏进去”，还要观察载体经过压缩、裁剪、转码或重新保存之后，信息是否仍然可恢复。一个看似不起眼的参数变化，可能会让隐藏数据完全失效，因此实际分析往往需要记录原始文件、处理步骤、工具版本和每次实验的结果。把这些信息整理成表格或清单，可以帮助读者复现实验，也能避免把偶然现象误认为稳定规律。🔍

| 实验 | 处理方式 | 预期结果   |
| ---- | -------- | ---------- |
| A    | 原图读取 | 成功提取   |
| B    | 无损保存 | 大概率成功 |
| C    | 有损压缩 | 可能失败   |

对于四只鹅的队列模型，观测到的方向可以表示为：

$$
y = x + \alpha fog + \epsilon
$$

其中 $x$ 是原来的位置，$fog$ 是雾，$\alpha$ 是等待的程度，$\epsilon$ 表示没有发生的事情。
